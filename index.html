Bạn hãy đề xuất cho tôi xem ghi ở chỗ nào của web để mọi người có thể xem được, hoặc tạo 1 tab riêng biệt về nội quy, bắt buộc phải đọc để đạt giải. Hỏi thêm là: Tôi điền thông tin về nội quy ở file google sheet để tiện thay đổi nó, hãy hướng dẫn tôi Để hiển thị nội quy rõ ràng mà không làm bảng sự kiện bị dài dòng, phương án tối ưu nhất là tạo Hệ thống 2 Tabs chuyển đổi ngay đầu trang: Tab 1: 🏆 BẢNG MỐC SỰ KIỆN & TRAO GIẢI (Bảng chính). Tab 2: 📜 NỘI QUY & THỂ LỆ SỰ KIỆN (Trình bày dạng từng thẻ quy định, bắt mắt, dễ đọc). Toàn bộ nội dung quy định sẽ được quản lý trực tiếp trên Google Sheet (Sheet Rules). Khi bạn thêm bớt hoặc sửa điều luật trên Sheet, website sẽ tự động cập nhật ngay lập tức. BƯỚC 1: TẠO SHEET "RULES" TRÊN GOOGLE SHEETS Mở file Google Sheet EVENT MEDIAN XL MÙA 2.14 của bạn. Bấm dấu + ở góc dưới bên trái để tạo thêm 1 trang tính mới. Đổi tên trang tính mới thành: Rules. Thiết lập 2 cột tiêu đề tại Hàng 1: A1: TieuDe (Tên điều luật, ví dụ: 1. Quy định nộp minh chứng, 2. Quy định nhân vật...) B1: NoiDung (Chi tiết quy định tương ứng). Ví dụ bạn điền trên Sheet Rules: A2: 1. Quy định về ảnh/video minh chứng | B2: Ảnh/Video phải rõ nét tên nhân vật (Fn), hòm đồ và chỉ số charm. Không chấp nhận ảnh chụp mờ hoặc qua chỉnh sửa photoshop. A3: 2. Thứ tự xét duyệt giải | B3: Ban Quản Lý sẽ ưu tiên trao giải cho người nộp đúng và sớm nhất tính theo thời gian lưu trên hệ thống. BƯỚC 2: CẬP NHẬT GOOGLE APPS SCRIPT ĐỂ ĐỌC TAB NỘI QUY Vào Google Sheet → Tiện ích mở rộng → Apps Script. Thay toàn bộ đoạn code trong Apps Script bằng đoạn mã dưới đây: JavaScript const FOLDER_ID = "ĐIỀN_FOLDER_ID_GOOGLE_DRIVE_CỦA_BẠN_VÀO_ĐÂY"; function doGet(e) { const action = e.parameter.action; const ss = SpreadsheetApp.getActiveSpreadsheet(); if (action === "getEvents") { const sheetEvents = ss.getSheetByName("Events"); const sheetSubs = ss.getSheetByName("Submissions"); const sheetRules = ss.getSheetByName("Rules"); // 1. Lấy dữ liệu Sự kiện const eventsData = sheetEvents.getDataRange().getValues(); const subsData = sheetSubs ? sheetSubs.getDataRange().getValues() : []; const events = []; for (let i = 1; i < eventsData.length; i++) { const row = eventsData[i]; const eventId = String(row[0]); if (!eventId) continue; const submissions = []; for (let j = 1; j < subsData.length; j++) { if (String(subsData[j][1]) === eventId) { submissions.push({ time: Utilities.formatDate(new Date(subsData[j][0]), "GMT+7", "dd/MM HH:mm"), playerName: subsData[j][2], proofUrl: subsData[j][3], note: subsData[j][4] }); } } let endDateStr = ""; if (row[13]) { endDateStr = Utilities.formatDate(new Date(row[13]), "GMT+7", "yyyy-MM-dd"); } events.push({ id: eventId, tt: row[1], title: row[2], r1_reward: row[3], r1_winner: row[4], r1_status: row[5], r2_reward: row[6], r2_winner: row[7], r2_status: row[8], r3_reward: row[9], r3_winner: row[10], r3_status: row[11], note: row[12], endDate: endDateStr, submissions: submissions }); } // 2. Lấy dữ liệu Nội quy (Sheet Rules) const rules = []; if (sheetRules) { const rulesData = sheetRules.getDataRange().getValues(); for (let k = 1; k < rulesData.length; k++) { if (rulesData[k][0] || rulesData[k][1]) { rules.push({ title: rulesData[k][0], content: rulesData[k][1] }); } } } return ContentService.createTextOutput(JSON.stringify({ events: events, rules: rules })) .setMimeType(ContentService.MimeType.JSON); } } function doPost(e) { try { const data = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheetSubs = ss.getSheetByName("Submissions"); const folder = DriveApp.getFolderById(FOLDER_ID); const blob = Utilities.newBlob(Utilities.base64Decode(data.fileData), data.mimeType, data.playerName + "_" + data.fileName); const file = folder.createFile(blob); file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW); sheetSubs.appendRow([ new Date(), data.eventId, data.playerName, file.getUrl(), data.note || "" ]); return ContentService.createTextOutput(JSON.stringify({ status: "success", url: file.getUrl() })) .setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() })) .setMimeType(ContentService.MimeType.JSON); } } Bấm Lưu (Đĩa mềm) → Bấm Triển khai (Deploy) → Quản lý các lần triển khai (Manage deployments) → Bấm biểu tượng Cây bút (Chỉnh sửa) → Chọn Phiên bản mới (New version) → Bấm Triển khai (Deploy).
